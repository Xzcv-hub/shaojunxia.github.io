abstract: >-
  GEAR is an open framework for optimizing LLM agent harnesses through evolutionary search and reproducible evaluation. A task agent generates execution evidence, while a meta agent uses evidence across tasks to propose reusable harness modifications. GEAR manages the search, HITCH runs fixed agent configurations and archives execution evidence, and REAR supports post-experiment analysis without modifying evaluation records.
